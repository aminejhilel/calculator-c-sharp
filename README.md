# 🧮 Calculator C#
--------------------------

A simple calculator application developed using **C#**. This project helps beginners practice basic programming concepts and arithmetic operations.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🖥️ User input and output
- 📚 Beginner-friendly code

## 🛠️ Technologies Used

- C#
- .NET

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aminejhilel/calculator-c-sharp.git
```

### 2. Open the project

Open the project folder in Visual Studio or Visual Studio Code.

### 3. Run the application

If the project contains a `.csproj` file, open a terminal in the project directory and run:

```bash
dotnet run
```

## 🎯 Project Objective

The goal of this project is to practice C# programming fundamentals, including variables, user input, arithmetic operators, and conditional statements.
